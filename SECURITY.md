# Security policy

## Supported versions

Security fixes are applied to the current `bet` branch. The `bluff` branch is
an integration branch and may contain unreleased changes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or leaked
credential. Use the repository's **Security** tab and select **Report a
vulnerability** to start a private discussion with the maintainer.

Include the affected commit or release, reproduction steps, expected impact,
and any suggested mitigation. You should receive an initial response within
seven days.
